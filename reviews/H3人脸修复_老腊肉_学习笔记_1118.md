## 一、作者原话要点（带时间点）

- [00:13–00:37] 常见的修脸是局部重绘，为了保留原人物和表情，denoise 一般设在 0.5 以下，所以模糊的脸修不清楚。这套工作流靠遮罩把脸的区域交给模型重新生成，原来很糊的脸也能出清楚五官。
- [03:04–03:57] 用三个扩展：
  - MaskVidExperiments：遮罩处理；
  - H3 FaceRefine：追踪、裁出人脸，修完再贴回去；脸检测模型用 face_yolov8n；
  - ComfyUI-VOSR2：做最后一轮细节修复，第一次运行会自动下载模型。
- [04:00–04:21] 分三段：①生成基础视频；②H3 第一阶段修脸；③VOSR2 第二阶段修脸。最后贴回原片。真正让脸变清楚的是中间那一段。
- [04:29–04:54] 基础视频用 Singularity V1.3 参考生成模型。稀疏注意力用 sol-attn，采样更快。Singularity 不是 Turbo 模型，所以加 Pika H3 Flex 八步加速 LoRA。
- [05:07–05:45] H3 Face Track + Crop 追踪并裁出人脸，画布 768×768。输出有三样：crops（裁出的人脸视频）、transform（每帧的裁切和缩放，贴回时要用）、画布宽高。
- [05:49–06:05] 采样条件用 MiniMax H3 Reference to Video。它输出的 latent 不用。
- [06:11–07:03] 关键：把遮罩引入采样。
  - SAM 3.1 用提示词「face」，先在首帧定位人脸，再在全片追踪；
  - MVEx Mask Cleanup 去掉细碎的小遮罩；
  - MVEx Mask To Latent Space 把像素空间的遮罩转到潜空间，这一步很重要；
  - Set Latent Noise Mask 把遮罩加到 latent 上。
- [07:06–07:18] 音频也这样处理：用一个 32×32 全黑遮罩，作用等于把音频锁住不改。
- [07:23–07:52] 采样：Euler、Beta 调度、8 步。模型通往采样的路上加 Differential Diffusion（局部重绘常用）。因为 latent 带遮罩，denoise 可以设成 1。
- [07:57–08:05] 「我们之前之所以人脸修复的效果不好，就是因为这个阶段得不到一个高质量的视频」。
- [08:05–08:18] 第二阶段用 VOSR2，upscale 设成 1：只加面部细节，不放大视频。
- [08:25–08:42] H3 Face Stitch Back 贴回，需要原视频、修好的视频和 transform。
- [08:46–09:33] 基础版的问题：脸靠近画面上沿（陶艺女孩抬头）时，贴回去会错位、扭曲。
- [09:33–10:35] 优化版改了三处：
  1. 修脸用的参考图只放脸，生成基础视频用的参考图放全身；
  2. 第一阶段 denoise 从 1 改成 0.5。设 1 修得最狠，但可能把原来的表情和面部细节一起改掉；在意保留原状态就设 0.5，看情况再往上提；
  3. 最关键的一处：把 SAM 的脸部遮罩接到 Face Stitch Back 的 masks 输入上。改完错位完全没有了。
- [10:43–11:31] 测试：横着的脸（躺在飞剑上）能检测和修复；转头、做表情、手在脸旁边时五官还清楚。
- [11:34–12:20] 镜头一直后拉、脸越来越小的测试：后半段原本糊成一团的五官修回了清楚轮廓。
- [12:24–12:44] 作者总结：价值在于把脸单独拿出来，让 H3 有足够画布重画五官；再把遮罩引入局部重绘。

## 二、工作流逐节点（共 95 个，其中 SetNode/GetNode 只是界面传线，走 API 时去掉）

### A 段：生成基础视频（我们不用，换成读入自己的片子）
- 30 UNETLoader：`Minimax-h3_Singularity_ref2va_Pruned_v1.3_int8`
  → 148 MiniMaxH3MemoryEfficientSageAttentionPatch
  → 147 稀疏注意力 BlockSparseAttention：方法 sol-attn，阈值 tau 1.3，从 20% 步开始到最后，最少令牌 12288，额外令牌 256，sink 选 exact_kv_and_rows
  → 121 LoRA `pika_h3_flex_turbo_8step_hd_ref2va` 强度 1.0
  → 存成 `model`，A、B 两段共用。
- 15 CLIPLoader：`qwen3vl_32b_minimax_h3_int8_convrot`（8 位，符合规矩）。
- 3 视频 VAE：`minimax_h3_video_vae_int8_convrot`；4 音频 VAE：`fp32`。
- 9 LoadImage 全身设定图 → 255/256 缩放（总像素 2 MP，再取 32 的倍数）→ 11 R2V（1344×768，124 帧）
  → 209 SelfLiftH3Sampler（euler、beta 8 步、latent upscaler 3d conv）→ 131/133 解码。
- 结果存成 `raw_video`、`raw_audio`。

### B 段：第一阶段修脸（核心）
1. **163 H3FaceTrackCrop**：输入 raw_video。
   - 参数：yolov8n、置信度 0.35、crop_factor 2.5、画布 768×768 manual、中心平滑 21、尺寸平滑 51、gaussian、per_frame、largest_face。
   - 输出 crops（存 `crops`）、transform（存 `transform`），宽、高、帧数接给 164。
2. **257 LoadImage 只有脸的参考图** → 258/259 缩放 → **164 MiniMaxH3ReferenceToVideo**。
   - 提示词留空，ref_image_size=match，宽高帧数取自 163。
   - 只用它的 conditioning，latent 不用。
3. 遮罩：
   - **233** 加载 `sam3.1_multiplex_fp16`；**234** 提示词「face」；
   - **235 SAM3_VideoTrack** 在 crops 上跟踪（阈值 0.5，最多 1 个目标，每帧检测）；
   - **236 SAM3_TrackToMask** 取 0 号目标；
   - **240 MVEx_MaskCleanup**：阈值 0.3，shrink_grow 先收缩 12 像素、至少持续 4 帧，edge_grow 16；
   - **241 MVEx_MaskToLatentSpace**：auto 按 VAE 压缩比，空间、时间都取 max，空间外扩 36、时间外扩 1、both。
4. 视频 latent：**244 VAEEncode(crops)** → **242 SetLatentNoiseMask**（接 241 的遮罩）。
5. 音频 latent：**250 VAEEncodeAudio(raw_audio)** → **252 SetLatentNoiseMask**，遮罩是 **251 SolidMask** 值 0、32×32，等于整段锁住不改。
6. **247 LTXVConcatAVLatent** 合成音视频 latent。
7. 采样：
   - 模型 → **254 DifferentialDiffusion**（1.0）→ **171 BasicGuider**（接 164 的 conditioning）；
   - **172** euler；**175 BasicScheduler** beta 8 步，**denoise 0.5**（优化版）；
   - **165** 随机种子；**174 SamplerCustomAdvanced**；
   - **183 VAEDecode** 解码，结果存 `1pass_video`。

### C 段：第二阶段和贴回
- **188 VOSR2ModelLoader** → **187 VOSR2Upscale**：upscale 1，颜色对齐 wavelet，tile 512/32，vae tile 1024/32。输入是 `1pass_video`。
- **191 H3FaceStitch**：原片 raw_video、修好的 187、transform，**masks 接 236（SAM 原始遮罩，没经过 Cleanup）**。
  - paste_region face_only，mask_dilation 24，feather 24，colour_match 1，blend 1，未检出的帧 fade_out。
- **192** 合成，带原音频。

## 三、和我们现在的 FaceRefine（swap1107/fr_run.py）的区别

| 项 | 老腊肉版 | 我们的 fr_run.py |
|---|---|---|
| 模型 | Singularity ref2va v1.3 int8 ＋ pika flex turbo 8 步 LoRA | fl2va 剪枝 int8 ＋ fl2v turbo 8 步 LoRA |
| 参考 | 只放脸的一张图（R2V） | 定版 05 胸像＋01 全身 |

| 第二阶段 | VOSR2 超分（倍率 1） | 没有 |
| 贴回 | 接 SAM 遮罩 | 不接遮罩 |
| 平滑窗口 | 21 | 速查表定 5（21 跟不上甩头） |
